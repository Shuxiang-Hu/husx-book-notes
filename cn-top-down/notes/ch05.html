05 · The Network Layer: Control Plane

The control plane determines how packets are routed through the network — routing algorithms compute shortest paths, OSPF handles intra-domain routing, BGP handles the Internet's inter-domain policy routing, and SDN allows software-defined control of the entire forwarding infrastructure.

Routing Algorithms

A routing algorithm finds the least-cost path through the network graph G=(N,E). Two families:

  • Link-State (LS) — each router broadcasts link costs to all routers (using link-state packets). Every router has a complete network map and runs Dijkstra's algorithm locally. Used by OSPF.
  • Distance-Vector (DV) — each router maintains a distance vector to all destinations and exchanges it with direct neighbors. Uses the Bellman-Ford equation: d_x(y) = min_v{c(x,v) + d_v(y)}. Distributed and decentralized. Used by RIP. Vulnerable to count-to-infinity problem.

Intra-AS Routing: OSPF

The Internet is organized into Autonomous Systems (AS) — groups of routers under a single administrative authority. Within an AS, intra-AS routing protocols run. OSPF (Open Shortest Path First) is the most common: it uses link-state flooding and Dijkstra's algorithm. OSPF advantages: security (authentication), multiple same-cost paths for load balancing, support for multiple metrics, hierarchical OSPF (with areas to reduce flooding).

OSPF messages are sent directly over IP (not TCP or UDP), with protocol number 89. Each router has a complete topology map of its area and computes shortest paths to all destinations.

Inter-AS Routing: BGP

BGP (Border Gateway Protocol) is the Internet's inter-domain routing protocol — the glue that holds the Internet together. BGP allows ASes to advertise reachability to IP prefixes. Two types: eBGP (between border routers in different ASes) and iBGP (within an AS, to distribute eBGP-learned routes).

A BGP route includes the prefix, the AS-PATH (list of ASes the advertisement passed through), and the NEXT-HOP. Route selection follows a complex set of rules (local preference, AS-PATH length, MED, iBGP/eBGP, IGP cost, router ID) rather than just shortest path — enabling policy-based routing.

The SDN Control Plane

In SDN, the control plane is physically separate from the data plane. A logically centralized SDN controller maintains a network-wide state database and installs flow table entries into distributed packet switches via the OpenFlow protocol. The controller itself consists of a communication layer (southbound API to switches), a network-wide state management layer, and a northbound API to applications.

SDN applications include load balancing, firewalls, traffic engineering, and network virtualization (creating overlay networks on top of physical infrastructure).

ICMP and Network Management

ICMP (Internet Control Message Protocol) is used by routers and hosts to report errors and exchange information. Common ICMP types: echo request/reply (ping), destination unreachable, time exceeded (used by traceroute to discover path). ICMP messages are encapsulated in IP datagrams.

SNMP (Simple Network Management Protocol) enables network administrators to query and configure managed devices. NETCONF/YANG is the modern successor: YANG is a data modeling language and NETCONF is an XML-based protocol for configuring network devices.
