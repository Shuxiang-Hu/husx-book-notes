07 · Wireless and Mobile Networks

Wireless networks introduce unique challenges — signal attenuation, hidden terminals, and mobility — solved by IEEE 802.11 (WiFi) for local access and 4G/5G cellular for wide-area coverage, with mobility management protocols allowing seamless handoff across cells.

Wireless Links and Signal Characteristics

Wireless communication differs from wired links in fundamental ways. Path loss: signal power decreases with the square of distance (free-space) or faster in built environments. Multipath propagation: signals reflect off surfaces, arriving at different times and phases (causing fading). Interference: multiple transmitters sharing the same spectrum cause mutual interference.

The hidden terminal problem: node A and C cannot hear each other but both can hear B — they may transmit simultaneously, causing collision at B. The exposed terminal problem: node B can hear C and avoids transmitting even though its transmission to A would succeed. CSMA/CA with RTS/CTS partially solves the hidden terminal problem.

CDMA (Code Division Multiple Access) allows multiple senders to share the same frequency band simultaneously. Each sender multiplies data bits by a unique chip sequence; receivers use the same code to extract the signal.

WiFi: IEEE 802.11 Wireless LANs

The 802.11 standard (WiFi) defines physical and MAC layers for wireless LANs. The basic service set (BSS) contains one access point (AP) and associated stations. WiFi operates in the 2.4 GHz, 5 GHz, and 6 GHz bands. Common standards: 802.11b (11 Mbps), 802.11a/g (54 Mbps), 802.11n (600 Mbps, MIMO), 802.11ac (multi-Gbps), 802.11ax (WiFi 6, OFDMA).

The 802.11 MAC uses CSMA/CA (Collision Avoidance): before transmitting, wait for DIFS after channel idle; then use random backoff. On receipt, ACK sent after SIFS. RTS/CTS optional: sender sends RTS, AP replies with CTS, clearing all other stations.

Cellular Networks: 4G LTE and 5G

Cellular networks divide geographic areas into cells, each served by a base station (eNodeB in 4G, gNB in 5G). The 4G LTE architecture has: user equipment (UE), radio access network (eNodeB), Evolved Packet Core (EPC — comprising MME for mobility management, Serving Gateway, PDN Gateway), and the public Internet.

LTE uses OFDMA (Orthogonal Frequency Division Multiple Access) on the downlink — dividing the channel into many narrow subcarriers. Multiple users are served simultaneously using different subcarrier/time slot assignments. LTE uplink uses SC-FDMA.

5G NR (New Radio) extends LTE with higher frequencies (mmWave bands at 24–100 GHz), massive MIMO (hundreds of antennas), network slicing (multiple virtual networks over same infrastructure), and latency below 1 ms for URLLC (ultra-reliable low-latency communications).

Mobility Management

When a mobile device moves from one cell to another, handover (or handoff) must occur without dropping active connections. In 4G, the source eNodeB coordinates with the target eNodeB to transfer state (X2 interface), then the MME updates the data path through the EPC.

Mobile IP provides network-layer mobility: a home agent (HA) at the home network and a foreign agent (FA) at the visited network cooperate. The HA intercepts packets destined for the mobile node's home address and tunnels them (via encapsulation) to the care-of address at the FA. The mobile node can use either indirect routing (through HA) or direct routing (after correspondent learns care-of address).
