06 · The Link Layer and LANs

The link layer moves frames between adjacent nodes on a single communication link — handling error detection, medium access coordination, and addressing at the level of hardware (MAC addresses) rather than software (IP addresses).

Link Layer Services

The link layer provides framing (encapsulating datagrams in link-layer frames), link access (coordinating medium access with MAC protocols), and reliable delivery. Not all link-layer implementations provide all services. The link layer is implemented in the network interface card (NIC) — a combination of hardware and software. Key error detection techniques:

  • Parity bits — single bit detects single-bit errors; 2D parity can also correct single-bit errors.
  • Checksum — as used in IP/TCP/UDP (relatively weak).
  • CRC (Cyclic Redundancy Check) — treats bits as polynomial coefficients; far more powerful than checksum, can detect burst errors up to r bits.

Multiple Access Protocols

When multiple nodes share a single broadcast channel, a multiple access protocol coordinates who transmits when. Three categories:

  • Channel Partitioning — divide channel into smaller pieces (TDM, FDM, CDMA). Efficient at high load, wasteful at low load.
  • Random Access — nodes transmit at full rate; handle collisions. Examples: ALOHA, CSMA/CD (Ethernet), CSMA/CA (WiFi).
  • Taking-Turns — nodes take turns; polling (master polls each node) or token ring (token passed around). Better efficiency than random access at moderate loads.

CSMA/CD (used by Ethernet): detect carrier first; if collision detected (during transmission), abort, send jam signal, back off exponentially. Minimum frame size constraint ensures collision detection works: transmission delay must exceed 2×propagation delay.

Switched Local Area Networks (LANs)

Every network adapter has a unique MAC address — a 48-bit address (written as six hex octets, e.g., 1A:23:F9:CD:06:9B) burned into the NIC ROM. MAC addresses are flat (unlike hierarchical IP addresses) and are used for link-local delivery.

ARP (Address Resolution Protocol) maps IP addresses to MAC addresses within a subnet. ARP is stateless and uses broadcast: a node broadcasts "who has IP 192.168.1.5?" and the owner replies with its MAC address. ARP entries are cached with a TTL.

Ethernet (IEEE 802.3) is the dominant wired LAN technology. Modern Ethernet is switched (not shared), running at 100 Mbps, 1 Gbps, or 10 Gbps over twisted pair or fiber. An Ethernet frame has: preamble (8B), destination MAC (6B), source MAC (6B), type (2B), payload (46–1500B), CRC (4B).

Link-Layer Switches

Switches are link-layer devices that transparently forward frames. They learn MAC addresses by examining source MAC addresses of incoming frames (self-learning), storing them in a switch table with the incoming port and a TTL. To forward: if destination MAC is in table, forward to that port; if not, flood to all ports except incoming.

VLANs (Virtual LANs) allow a single physical switch to act as multiple logical switches. Ports are assigned to VLANs; frames are tagged with an 802.1Q VLAN tag. VLANs provide traffic isolation, security, and flexible topology without physical rewiring.

Data Center Networking

Modern data centers contain tens to hundreds of thousands of servers. The fat-tree topology (or similar folded-Clos topology) connects servers through layers of access, aggregation, and core switches, providing massive bandwidth and multiple paths for load balancing. Specialized protocols handle intra-data-center traffic: ECMP (Equal-Cost Multi-Path) for load balancing, RDMA (Remote Direct Memory Access) for low-latency storage.
