01 · Computer Networks and the Internet

The Internet is a network of networks — a collection of billions of connected devices communicating through protocols that define the rules of engagement from physical bits to application messages.

What Is the Internet?

The Internet can be described from two angles. The nuts-and-bolts view sees it as hundreds of millions of connected computing devices — hosts or end systems — linked by communication links (fiber, copper, radio, satellite) and packet switches (routers and link-layer switches). The services view sees it as an infrastructure that provides services to applications, ranging from the Web and email to streaming video and instant messaging.

A protocol defines the format and order of messages exchanged between entities, and the actions taken on transmission or receipt. All Internet communication is governed by protocols; TCP, IP, HTTP, DNS, and Ethernet are all examples.

Network Edge and Access Networks

The network edge comprises end systems — laptops, smartphones, web servers, IoT sensors. Access networks connect end systems to the first router (the edge router). Common access technologies include DSL (using existing telephone lines), cable (HFC — hybrid fiber-coaxial), fiber-to-the-home (FTTH), WiFi (802.11), and Ethernet (institutional LANs).

The physical media over which bits travel are either guided media (twisted-pair copper, coaxial cable, fiber-optic) or unguided media (radio, microwave, satellite).

The Network Core: Packet vs Circuit Switching

The network core is the mesh of packet switches and links that connects end systems. Two fundamental switching paradigms compete:

Packet switching breaks application messages into packets and sends each packet independently through the network. Routers use store-and-forward transmission — the entire packet must arrive before it can be forwarded. This causes queuing delay when traffic bursts exceed link capacity.

Circuit switching pre-allocates end-to-end resources for the duration of a call. Traditional telephone networks use circuit switching. Resources are guaranteed but may be wasted when a connection is idle. Multiplexing can be FDM (frequency-division) or TDM (time-division).

Delay, Loss, and Throughput

Packets suffer four types of delay at each router: nodal processing delay (checking bit errors, finding output link), queuing delay (waiting in queue for transmission), transmission delay (L/R, packet length over link rate), and propagation delay (d/s, distance over propagation speed).

Throughput is the rate at which bits are transferred end-to-end. In a multi-link path, throughput equals the minimum link rate — the bottleneck link.

Protocol Layers and the Internet Model

Networks organize functionality into layers. Each layer provides a service to the layer above and relies on the layer below. The Internet protocol stack has five layers:

  • Application — HTTP, SMTP, DNS, FTP. Messages.
  • Transport — TCP, UDP. Segments / datagrams.
  • Network — IP, routing. Datagrams.
  • Link — Ethernet, 802.11. Frames.
  • Physical — Bits on the wire.

Encapsulation: each layer adds its own header (and sometimes trailer) wrapping the payload from the layer above. A router processes only up through the network layer; a link-layer switch only up through the link layer.

Networks Under Attack: Security

The Internet was originally designed with openness, not security, in mind. Today's threat landscape includes:

  • Malware — viruses and worms that infect end systems via network connections.
  • DDoS (Distributed Denial-of-Service) — flooding a target with traffic from thousands of compromised hosts (a botnet).
  • Sniffing — passively recording packets on a shared link (packet sniffer).
  • IP Spoofing — injecting packets with a false source address.

History of Computer Networking

The Internet grew from ARPANET (1969), the first packet-switched network. Key milestones: TCP/IP standardized in 1974 (Cerf & Kahn); the DNS introduced in 1983; the World Wide Web proposed by Tim Berners-Lee in 1989; the commercialization of the Internet in the early 1990s; the explosion of broadband and wireless in the 2000s; and the mobile Internet era from 2007 onward.
